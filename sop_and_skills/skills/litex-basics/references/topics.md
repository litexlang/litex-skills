# Select a mathematical topic

These are on-demand references, not six automatically activated skills. Read
one when the task reaches its trigger; return to the task workflow afterward.

| Topic | Trigger | Relevant task |
| --- | --- | --- |
| [Algebra, equality and order](topics/algebra.md) | A calculation jump, cancellation or estimate does not verify | proof writing; equality/inequality cleanup |
| [Sets and functions](topics/sets-functions.md) | A carrier, membership, mapping or callable interface is unclear | concept modeling; proof writing |
| [Existence and selection](topics/existence.md) | Witness dependency, uniqueness or choosing a function is central | concept modeling; proof writing |
| [Logic and scope](topics/logic-scope.md) | A quantifier, premise, proof body or helper name is misunderstood | proof writing; review |
| [Induction and recursion](topics/induction.md) | An indexed invariant or recursive construction needs a base/step | proof writing; chapter translation |
| [Modules and context](topics/modules.md) | A file relies on imports/exports or a loaded prefix | translation; version migration |

For analysis or geometry, first use the matching live showcase's README,
mathematical interfaces and configuration through `litex-reference` when
available. The common topics above do not replace a subject library.

Promote a topic to a separate skill only when it has a distinct trigger,
multi-step workflow and meaningful independent acceptance task. A static
syntax list or one misconception remains a reference card.
