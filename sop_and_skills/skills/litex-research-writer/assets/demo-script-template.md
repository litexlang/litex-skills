# Three-Minute Litex Demo Script

> Imported reference snapshot (2026-10-13). For execution use [the hub contract](../../litex-reference/references/execution.md). Repository paths and author preferences are scoped to the source project; dated examples are historical until replayed.


1. Show the natural-language problem.
2. Show the Litex statement.
3. Show the Litex proof.
4. Run the verifier.
5. Point to accepted facts and `verified_by` output.
6. If it fails, show blocker classification and next action.
7. Close with what this produces: checked proof data, verifier trace, benchmark evidence, or a minimal blocker.
