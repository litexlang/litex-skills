# SOP directory

A SOP combines skills into a task-specific sequence and defines that task's
acceptance scope. It can be followed by a human or an agent with the needed
file and execution capabilities.

- [IMO geometry](imo-geometry/README.md): formulate a contest problem, construct
  a proof, keep accepted Session context and verify the saved answers.

Choose the relevant skill from [the content index](../README.md) when a task
needs only a local proof or definition. Agent-specific loading and configuration
are shown separately in [the Generic Agent example](../../generic_agent_example/README.md).
