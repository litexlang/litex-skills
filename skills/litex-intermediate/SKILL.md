# Litex intermediate

**Prerequisite:** [litex-basics](../litex-basics/SKILL.md).

This layer is for proofs that need an explicit method beyond stating a direct fact
or a short definition→theorem chain. Content will be filled from the golitex
Manual / Cheatsheet proof-action sections and the basics topic guides.

Do not load this skill for API smoke tests of elementary definitions.
When a section is promoted out of stub form, keep one positive and one negative
checked example beside it.
